🗄️ Paperwork
Drop the scans in — Wren reads them, proposes where they go, you say yes
Everything the setting holds on paper, readable on a tablet. Drag a folder of PDFs or photos onto the drop zone: each file is queued and processed in the background, so the browser does not block and closing this tab loses nothing. Wren extracts the text (OCR only when there is no text layer), then the local model on the Ascent proposes a heading, a date and a title. Nothing is filed until you accept it — a policy under the wrong heading is worse than one that was never filed. Scanned nursery paperwork carries child and staff personal data, so it never reaches a cloud model; if the Ascent is unreachable the file is still stored and searchable, just flagged for you to file by hand.
